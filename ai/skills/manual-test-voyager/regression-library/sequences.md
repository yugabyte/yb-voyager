# Sequences & identity

Why it matters: after data import, every sequence / identity column must be advanced past the max migrated value, or the first application insert collides with migrated data. This is a recurring bug class and a QA "commonly impacted" area. `import data` prints "setting resume value for sequences" — verify it actually worked.

## Scenarios

### sequences-1: identity + explicit sequence advance
- Flow: offline
- Origin: QA priority + validated in the skill's smoke fixture
- Setup: table with `GENERATED BY DEFAULT AS IDENTITY` and a table with an explicit `CREATE SEQUENCE ... START n` + `DEFAULT nextval(...)`
- Command: full offline pipeline
- Expected oracle: after import, a fresh insert on the target gets an id strictly greater than the max migrated id, for both identity and explicit-sequence tables.
- Status: validated (migrated 5000 orders → fresh insert = 5001; widget_seq migrated to last=599 → fresh insert = 600)

### sequences-2: sequence ownership & OWNED BY
- Flow: offline
- Origin: coverage — ownership metadata via pg_depend (see `yb.py` sequences validate)
- Setup: sequence OWNED BY a column
- Command: full offline pipeline
- Expected oracle: ownership preserved on target; dropping the table drops the sequence.
- Status: seeded

### sequences-3: sequence values under live CDC
- Flow: live
- Origin: sequences advanced by inserts during the CDC phase, not just snapshot
- Setup: live migration; source_delta inserts new rows (consuming sequence values) after snapshot
- Command: live pipeline + delta
- Expected oracle: post-cutover, target sequence is past the highest value produced during CDC, not just the snapshot max.
- Status: seeded

### sequences-4: cache / cycle / non-default increment
- Flow: offline
- Origin: edge — CACHE, CYCLE, INCREMENT BY, MINVALUE/MAXVALUE
- Setup: sequences with each non-default option
- Command: full offline pipeline
- Expected oracle: options preserved; resume value correct despite caching. (Note the `overriding cache option` NOTICE on import — confirm final behavior is correct.)
- Status: seeded
